To Run the Full Application:

# 1. Install PHP 7.4+ from https://windows.php.net/download/
# 2. Install MySQL/MariaDB
# 3. Run setup script:
setup.bat
# 4. Configure database in .env file
# 5. Create database:
mysql -u root -p < db/schema.sql
mysql -u root -p < db/sample_data.sql
# 6. Start server:
composer start
# 7. Open: http://localhost:8000
Note: PHP is not currently installed on your system. You'll need to install PHP first to run the full application.
